# Backend

No separate backend implementation currently exists in this repository.

The Crestia Ventures site sections are static HTML/CSS/JavaScript pages and React frontends. There is no server-side API, database layer, or PHP application source in the project today.

## Future notes

- GoDaddy WordPress hosting is primarily PHP + static file hosting.
- If a backend is added later, place it here and document hosting constraints in `docs/deployment-guide.md`.
- Do not assume Node.js server runtimes are available on standard GoDaddy WordPress plans.
